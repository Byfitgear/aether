## ✨ 核心特性

- 🎨 **可视化编辑器** — 所见即所得的页面编辑体验
- 📝 **联系表单** — 内置 `[aether_contact_form]` 短代码，开箱即用
- 🔒 **无需注册** — 免费版无需 API Token，安装即可使用
- 🖼️ **图片优化** — 自动压缩、WebP 转换
- 💨 **CSS 优化** — 自动生成页面级 CSS，提升加载速度
- 📱 **响应式** — 完美适配移动端
- 🧩 **模板管理** — 支持首页、文章页、404 页等模板自定义
- 🛡️ **反垃圾** — Honeypet 保护，有效阻止垃圾表单提交

## 📦 快速开始

### 安装

```bash
# 方式一：WordPress 后台
1. 下载 wordexpress-aether.zip
2. 后台 → 插件 → 新增插件 → 上传插件
3. 激活即可使用

# 方式二：命令行
cd /wp-content/plugins
wget https://github.com/Byfitgear/aether/releases/latest/download/wordexpress-aether.zip
unzip wordexpress-aether.zip
mv wordexpress-aether aether
```

### 使用联系表单

在任意页面或文章中插入：

```
[aether_contact_form]
```

自定义参数：
```
[aether_contact_form 
    title="联系我们"
    button_text="发送消息"]
```
