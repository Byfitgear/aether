# Contributing to Aether

Thank you for your interest in contributing to Aether! We welcome all contributions, whether it's bug reports, feature suggestions, documentation improvements, or code changes.

## 🐛 Reporting Bugs

Before creating a bug report, please check the existing issues to see if the problem has already been reported. When creating an issue, please include:

- WordPress version you're using
- PHP version
- Steps to reproduce the bug
- Expected vs. actual behavior
- Screenshots if applicable

## 💡 Suggesting Features

We love hearing about new ideas! Please open an issue with the "feature request" label and describe:

- What problem would this feature solve?
- How would you expect it to work?
- Any mockups or examples?

## 📝 Code Contributions

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/my-feature`)
3. Make your changes
4. Test thoroughly
5. Commit with clear messages (`git commit -m 'Add: my new feature'`)
6. Push to your fork (`git push origin feature/my-feature`)
7. Open a Pull Request

### Coding Standards

- Follow WordPress coding standards
- Use PSR-12 for PHP formatting
- Include comments for complex logic
- Write tests when possible

## 📖 Documentation

Documentation improvements are always welcome! This includes:

- README updates
- Adding screenshots
- Translating strings
- Improving inline code comments

## 🌍 Translations

Aether supports WordPress translation infrastructure. If you'd like to translate Aether into your language, visit the [WordPress translation directory](https://translate.wordpress.org/projects/wp-plugins/aether).
